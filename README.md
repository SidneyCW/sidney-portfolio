# Sidney's Portfolio

A mountaineering ⛰️ coffee ☕ coding 💻 themed portfolio built with Vite + React.
Projects get a climbing grade and a coffee-cup fuel rating, because every build is an ascent.

## Running it

```bash
npm install
npm run dev
```

## Stack

- React 19 + Vite
- Framer Motion for the entrance animations
- Lucide for icons
- Plain CSS theme (espresso darks, alpenglow amber, pine accents) in `src/index.css`
